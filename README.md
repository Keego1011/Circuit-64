# Circuit-64

## Descripción
Circuit-64 es un videojuego de carreras en el que el jugador controla un coche y debe completar 3 vueltas a un circuito mientras intenta conseguir el menor tiempo posible.

El objetivo es superar los propios récords y mejorar el tiempo en cada carrera.

## Características
- Control de un coche de carreras.
- Circuito de carreras.
- Sistema de 3 vueltas.
- Cronómetro para registrar los tiempos.
- Sistema para guardar el mejor tiempo.
- Competencia contra el propio tiempo.

## Controles
| Tecla | Acción |
|---|---|
| W | Acelerar |
| S | Frenar |
| A | Girar a la izquierda |
| D | Girar a la derecha |

## Tecnologías utilizadas
- C++
- OpenGL
- GLEW
- GLFW
- Visual Studio

## Objetivo del proyecto
Desarrollar un videojuego de carreras utilizando C++ y OpenGL, implementando movimiento del vehículo, cronómetro y un sistema de vueltas.
